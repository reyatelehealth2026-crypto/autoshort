# Technical Proposal: Shorts Factory Evolution (Phase 1)

## 1. Video Generation Integration (The Engine)
- **Architecture**: Implement a serverless backend (e.g., Node.js/Python) to handle long-running API calls to video providers.
- **Providers**: 
    - **Runway Gen-3 / Kling / Luma Dream Machine**: For high-fidelity scene generation from the prompts currently generated by the React UI.
    - **Workflow**: 
        1. UI sends Script JSON to Backend.
        2. Backend triggers parallel generation requests per scene.
        3. Webhook/Polling mechanism to notify UI when video segments are ready.
        4. Cloud assembly using FFmpeg to stitch segments with background music.

## 2. Agentic Interface (The Brain)
- **Concept**: Transition from a static form to a "Chat-first" or "Hybrid" UI.
- **Mechanism**:
    - Use an LLM (Gemini 2.0/3.0) as an orchestrator.
    - **Input**: "Make the transition between scene 1 and 2 faster and add a dramatic zoom."
    - **Action**: The Agent parses the command, updates the underlying Script JSON, and triggers a re-generation of specific segments.

## 3. Digital Twins & AI Avatars (The Face)
- **Integration**:
    - **HeyGen / HeyGen Interactive API**: For high-quality talking head generation.
    - **ElevenLabs**: For superior voice cloning and emotive narration.
- **Workflow**:
    - User uploads a 1-min sample of themselves.
    - AI creates a "Digital Twin".
    - In Shorts Factory, the script is synced to the Twin's lip movements automatically during the final render.

## Immediate Next Steps
1. Setup a basic Node.js proxy to handle API authentication and rate limiting.
2. Select one primary video API (e.g., Kling) for initial integration tests.
3. Refactor `ShortsCreator.jsx` to support "Chat-to-Modify" functionality.
